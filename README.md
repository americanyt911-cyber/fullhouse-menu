# Full House — меню и заказ

Telegram Mini App клуба Full House: кабинки PlayStation, кальяны, напитки и снеки с остатками, корзина и режим кассы.

## Как устроено

| Файл | Что это |
| --- | --- |
| `src/app.html` | Исходник: разметка, стили и логика в одном файле. Каталог (цены, остатки, кабинки) лежит в начале скрипта, раздел «1. КАТАЛОГ». |
| `build.py` | Собирает из исходника готовую страницу и подключает скрипт Telegram. |
| `index.html` | Готовая страница. Её отдаёт GitHub Pages и открывает бот. Руками не править. |

## Как изменить меню

1. Поправить данные в `src/app.html`.
2. Запустить `python3 build.py`.
3. Закоммитить `src/app.html` и `index.html`.

## Что пока демо

- Сеты и снеки с ценами взяты из печатного меню клуба. Кабинки, кальяны, напитки и все остатки — примеры.
- Состояние хранится в браузере каждого телефона: гость и касса не видят изменения друг друга. Для этого нужен сервер.
- Оплата не подключена, деньги не списываются.
- Режим кассы внутри Telegram открывается пятью нажатиями на логотип. Это не защита, а скрытие от случайных нажатий.
