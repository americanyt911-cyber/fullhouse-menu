# Full House — меню и заказ

Telegram Mini App клуба Full House: кабины PlayStation, кальяны, напитки и снеки с остатками, корзина и касса для сотрудников.

## Как устроено

| Файл | Что это |
| --- | --- |
| `catalog.json` | Меню: кабины, кальяны, напитки, снеки, цены. Его читают и страница, и сервер. |
| `src/app.html` | Исходник страницы: разметка, стили и логика в одном файле. |
| `build.py` | Собирает из исходника и меню готовую страницу и подключает скрипт Telegram. |
| `index.html` | Готовая страница. Её отдаёт GitHub Pages и открывает бот. Руками не править. |
| `worker/bot.js` | Сервер на Cloudflare Workers: бот и API для страницы. |
| `worker/core.js` | Правила клуба: остатки, кабины, заказы, доступ к кассе. |
| `wrangler.jsonc` | Настройки Cloudflare. Лежит в корне, поэтому при подключении репозитория ничего указывать не нужно. |

## Как это работает вживую

- Остатки, статусы кабин и заказы хранятся на сервере и одинаковы на всех телефонах. Страница обновляет их сама: у гостя раз в 15 секунд, у кассы раз в 6.
- Гость оформляет заказ в Telegram. Заказ сразу уменьшает остатки, занимает кабину и приходит сотрудникам сообщением от бота. Оплата на кассе.
- Бронь кабин на время: гость выбирает день, начало и длительность, касса подтверждает кнопкой в Telegram или в приложении. Клуб круглосуточный, шаг 30 минут, бронь открыта на 3 дня вперёд. Если гость не пришёл за 15 минут после начала, бронь снимается сама. Бронь по звонку касса ставит из карточки кабины. Правила лежат в `catalog.json`, раздел `booking`.
- Касса открывается только сотрудникам. Первый, кто отправит боту `/kassa`, становится владельцем. Остальные отправляют `/kassa`, владелец подтверждает. Список сотрудников: `/staff`.
- Если сервер недоступен, страница показывает демо на примерных данных.

## Как изменить меню

1. Поправить `catalog.json`.
2. Запустить `python3 build.py`.
3. Закоммитить изменения. Страница обновится через GitHub Pages, сервер — через Cloudflare.

## Что пока примерное

- Меню, цены, кабины, кальяны и вкусы — по данным владельца. Число кальянов в клубе (`hookahTotal`) — пример.
- Начальные остатки — примеры. Реальные числа выставляются в кассе.
- Онлайн-оплаты нет.
